# Calculator-CS

Aplicatie consola in C# care efectueaza cele 4 operatii aritmetice (+, -, *, /)
Impartirea la zero este semnalata ca eroare

## Cum se ruleaza
1. Clonati repository-ul: `git clone https://github.com/vstpirate/Calculator-CS.git`
2. Intrati in folder: `cd Calculator-CS`
3. Rulati comanda: `dotnet run`
4. Pentru iesire lasati primul numar gol si apasati Enter
